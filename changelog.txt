opengram - changelog

opengram is an unofficial fork of Telegram Desktop. Version numbers follow the
Telegram Desktop release it is based on.

7.3.0

- Own application identity: a separate app id, config folder and autostart entry,
  so opengram installs and runs next to Telegram Desktop without touching its
  profile or its data folder.
- De-branded interface: window titles, the tray, menus, the intro screen, the
  About box and the update checker now talk about opengram.
- No telemetry: crash reports and usage events are not sent anywhere anymore.
- Crash reports are shown in a window with a copy button and a button that opens
  a pre-filled GitHub issue. Nothing is uploaded automatically.
- Auto-update is kept.
- Removed Snap, UWP and the upstream release tooling.
